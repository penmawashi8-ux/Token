クレデンシャルの作成手順

1
Google Cloud Console でプロジェクトを作成または選択
2
「APIとサービス」→「ライブラリ」で YouTube Data API v3 を検索して有効化
3
「APIとサービス」→「OAuth 同意画面」でアプリを設定 （テスト用は外部を選択）
4
「認証情報」→「認証情報を作成」→「OAuth クライアント ID」 でアプリの種類にウェブアプリケーションを選択
5
承認済みのリダイレクト URI に以下を追加してクライアントIDとシークレットを取得
リダイレクト URI（コピーして貼り付けてください） http://localhost:5000/callback
